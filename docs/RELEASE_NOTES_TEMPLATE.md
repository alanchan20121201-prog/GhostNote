# GhostNote 幽灵便签

> 把一句话，刻在桌面上。

你有没有过这种时刻：正在专注做事，脑子里却挂着另一件事——"下午三点回个电话""记得改 Dockerfile 里的端口""这版别再用 SQLite 了"。

写在便签纸上会丢，贴在桌面快捷方式上会挡住图标，用待办软件又得先打开软件再找到那条待办。**真正需要的，只是一句话，静静地待在屏幕上，看得见，又不挡路。**

GhostNote 就是为这个瞬间做的：它没有主界面，只活在系统托盘里。按下 `Ctrl + Alt + N`，弹出输入框，敲一行字，回车。这行字就变成了印在桌面上的浮水印——**置顶显示，但鼠标可以完全穿透**，你照样能点开它后面的窗口、拖动图标、框选文件，它不会挡住任何操作。

## 它特别在哪

- **像浮在水面上，而不是贴了张纸**：无边框、无标题栏、无背景，只有一行浅灰色大字（微软雅黑 Light）。文字带一层深色描边，白底文档和深色壁纸上都不会糊掉。
- **真的点不到**：窗口带 `WS_EX_TRANSPARENT | WS_EX_LAYERED` 扩展样式并常驻 `HWND_TOPMOST`，鼠标点击直接穿透到下面的桌面和软件。
- **想改位置？按住 Ctrl + Alt 再拖**：因为窗口本身收不到鼠标消息，拖拽走的是全局鼠标钩子，不用先关掉穿透。
- **关掉再开，位置还在**：文字内容和屏幕坐标保存在 `%AppData%\GhostNote\state.json`，重启后原样回来。
- **本体只有一个 exe，不到 1MB**：不装服务、不写注册表、不联网、不加载任何第三方 UI 库。

## 怎么用

| 操作 | 效果 |
| --- | --- |
| `Ctrl + Alt + N` | 在屏幕中央弹出输入框，输入文字后按 `Enter` 保存 |
| `Esc` | 取消本次输入 |
| `Ctrl + Alt + 鼠标左键拖动` | 把水印拖到屏幕任意位置 |
| 托盘图标右键 → 字号 | 小 / 中 / 大三档，点一下立即生效 |
| 托盘图标右键 | 修改文字 / 隐藏或显示水印 / 退出 |
| 双击托盘图标 | 打开输入框 |

小提示：

- 输入框里**留空并回车**，等于清掉当前水印。
- 托盘菜单里的「隐藏水印」只是暂时藏起来，文字和位置仍然保留。
- 想微调颜色，改 `state.json` 里的 `Foreground`（形如 `#B3E8E8E8`，前两位是透明度），重启生效。

## 安装

1. 下载下面的 `GhostNote-vX.Y.Z-win-x64.exe`。
2. 双击直接运行，不需要安装，也不会弹 UAC。
3. 首次运行如果提示缺少运行库，请先安装 **.NET 8 桌面运行时（Desktop Runtime，x64）**：
   <https://dotnet.microsoft.com/download/dotnet/8.0>

> 为什么需要运行时？因为安装包被刻意控制在 5MB 以内。WPF 的运行时依赖被外部化后，exe 只有约 1MB；如果把它打包成"零依赖"版本，体积会膨胀到 60MB 以上，跟这个工具的定位不符——一个随手可用的小工具，不该占掉半个下载页。
>
> 注意：WPF 不支持 `PublishTrimmed` 裁剪（会剪掉 XAML 的反射依赖导致运行时崩溃），所以这里选择「框架依赖 + 单文件」来达成体积目标。

## 已知限制

- 仅支持 Windows 10 / 11（x64）。
- 水印窗口不参与输入，因此**无法用鼠标点击选中文字或复制**，改字请走 `Ctrl + Alt + N`。
- 少数全屏独占程序（如部分游戏的全屏模式）可能盖住置顶水印，切成无边框窗口模式即可正常显示。
- 只有一条水印。这个工具解决的就是"只记一句话"，不做多便签管理。
